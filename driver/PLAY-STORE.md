# Google Play release checklist

This driver project is configured for **Android API 36** and release R8/ProGuard minification.

## 1. Install the Android 16 SDK

In Android Studio, open **SDK Manager** and install:

- Android 16 / API 36 platform
- Android SDK Build-Tools 36.0.0

The same API 36 settings are present in `app.json` (`expo-build-properties`), `android/build.gradle`, and `android/gradle.properties`.

## 2. Build a signed release App Bundle

From the `driver` directory, install dependencies:

```bash
npm ci
```

Then open `driver/android` in Android Studio and choose:

**Build → Generate Signed App Bundle / APK → Android App Bundle → release**

Sign with your normal **upload key**. Do not share your keystore or passwords. The project version is **1.0.1 (versionCode 2)**; increase it again for subsequent uploads.

The App Bundle will be generated at:

```text
android/app/build/outputs/bundle/release/app-release.aab
```

## 3. Upload the matching deobfuscation file

Release builds now have `minifyEnabled true` and optimized ProGuard rules. After building the AAB, find its mapping file at:

```text
android/app/build/outputs/mapping/release/mapping.txt
```

Upload that `mapping.txt` in Play Console under the release's **Deobfuscation files** section.

**Important:** upload the mapping file generated by the exact same release build as the AAB. Do not reuse a mapping file from an older build. This file is generated locally and is intentionally not committed in the source ZIP.

## 4. Confirm notification audio after release shrinking

The release configuration includes `res/raw/keep.xml` so resource shrinking retains `delivery_alert.wav`. After installing the release build, use the Home bell or **Settings → Delivery alerts → Test alert sound**.

For live background job alerts, deploy the accompanying `api/src/push.ts` update and restart the API.

## If regenerating the native project

`app.json` retains the API 36 and R8 settings for Expo prebuild. Review native changes before overwriting the included `android` directory, and preserve the notification sound resource keep rule.
