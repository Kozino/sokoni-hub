SOKONI DRIVER — PLAY API 36 + R8 UPDATE

This archive includes the complete driver redesign, colour refinements, audible
job alerts, and the Google Play target API/deobfuscation update. It also includes
the required api/src/push.ts server change.

PLAY CONSOLE CHANGES
- Android compile SDK and target SDK: 36
- Android build tools: 36.0.0
- Driver version: 1.0.1 (versionCode 2)
- Release R8/ProGuard minification: enabled
- Release resource shrinking: enabled
- delivery_alert.wav is explicitly retained during resource shrinking

BUILD AND UPLOAD
1. Extract this archive and run npm ci in the driver folder.
2. In Android Studio SDK Manager, install Android 16 / API 36 and Build-Tools 36.0.0.
3. Open driver/android in Android Studio.
4. Choose Build > Generate Signed App Bundle / APK > Android App Bundle > release.
5. Sign with your normal upload key and upload the generated app-release.aab.

AAB output:
driver/android/app/build/outputs/bundle/release/app-release.aab

DEOBFUSCATION FILE
After that exact release build, upload this file in the release's Deobfuscation
files section in Play Console:

driver/android/app/build/outputs/mapping/release/mapping.txt

The mapping file is generated during the release build and is not included in
this source archive. Always upload the mapping from the same build as the AAB;
never reuse an older mapping. See driver/PLAY-STORE.md for the full checklist.

REQUIRED FOR REAL BACKGROUND JOB ALERTS
Copy the included api/src/push.ts over the same file in your existing API, then
build/restart the API. This changes only the driver job-alert channel and sound.
Buyer and vendor notification behaviour is unchanged.

TEST THE SOUND
Use the bell on Home, or Settings > Delivery alerts > Test alert sound.
A clearly labelled local test notification arrives after 2 seconds.
Allow notification permission and check the device notification volume.
Android's Delivery job alerts channel must not be silent or blocked.
